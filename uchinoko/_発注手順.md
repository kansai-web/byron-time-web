# うちの子グッズ 注文が入ってから発送までの手順

このファイルは配信されません（`.assetsignore` で `*.md` を除外）。

**ひとことで言うと**：お客様に3回だけ触れてもらいます。
① 注文フォーム → ② LINEで写真 → ③ お届け先フォーム。お支払いはその後です。

---

## 全体の流れ

| # | 何が起きるか | 誰が動くか |
|---|---|---|
| 1 | 注文フォームが送信される → Gmailに `【うちの子】BT-…` が届く | ー |
| 2 | LINEにお客様から写真が届く | Yukari |
| 3 | ChatGPTで加工 → 仕上がりイメージをLINEで送る | Yukari |
| 4 | OKをもらう | Yukari |
| 5 | **お届け先フォームのURLをLINEで送る** | Yukari |
| 6 | Gmailに `【お届け先】BT-…` が届く | ー |
| 7 | Squareで請求書を発行してメール送信 | Yukari |
| 8 | 入金を確認 | Yukari |
| 9 | ヨツバでデザインを作ってカートに入れる | **Yukari** |
| 10 | **注文画面に住所を入力・代行発送を指定** | **クー** |
| 11 | 内容を確認して発注（＝支払い） | **Yukari** |
| 12 | 発送の連絡をLINEで送る | Yukari |

## クーに頼めること・頼めないこと

**頼めること**
- Gmailの `【お届け先】BT-…` から住所を読み、**ヨツバの注文画面に貼り付ける**
- 「納品書を送付先に同梱しない（**代行発送**）」の指定
- 入力し終わった内容を読み上げて、メールと突き合わせる

**頼めないこと（Yukariの手が必要）**
- **シミュレーターへの画像アップロード** … パソコンのファイル選択の窓は、クーからは触れません
- **発注の確定（支払い）** … 買う操作は本人が行います

⚠️ クーが入力してもミスの可能性はゼロではありません。**確認は必ずYukariが行ってください。**
ただしコピー＆ペーストで運ぶので、目で見て手で打ち直すより事故は起きにくくなります。

**頼み方**：注文が来たら「BT-260822-4821 の住所をヨツバに入れて」と言えば通じます。

---

## ヨツバで気をつけること

- **クレジットカードで払うにはログインが必要**（ヨツバFAQ）。先にログインしておく
- デザインは**カートに入れたタイミングで確定**します。入れる前に見直すこと
- 「納品書を送付先に同梱しない（代行発送）」を選ぶと、
  『弊社の名前とご購入金額は分からないように、ご注文者様名義で発送』されます。**選び忘れると金額入りの納品書が同梱されます**
- デザインは1年保存され、デザインIDで呼び出せます。**リピート注文のときは作り直さなくて済みます**
- 別々の注文をまとめて送ることはできません（同梱不可）

## LINEで送る文面のひな形

### ① 仕上がりイメージを送るとき

```
お待たせしました。仕上がりのイメージができました。

こちらでいかがでしょうか。
「ここをもう少し」というところがあれば、遠慮なくおっしゃってください。

気に入っていただけましたら、お届け先をお伺いします。
このイメージをご覧になってお断りいただいても、料金は一切かかりません。
```

### ② お届け先フォームを案内するとき

```
ありがとうございます。それではお届け先をお伺いします。

こちらのフォームからご入力ください。
https://byron-time-web.otona-plus40.workers.dev/uchinoko/address.html

受付番号は BT-260822-4821 です。
郵便番号を入れると、ご住所が途中まで自動で入ります。
```

※ 受付番号は毎回書き換えること。

### ③ お支払いの案内をするとき

```
お届け先をありがとうございました。

お支払いのご案内を、Square（スクエア）という決済サービスから
メールでお送りしました。ご確認ください。
（迷惑メールに入ってしまうことがあります）

メールのボタンからお手続きいただけます。
カードをお使いになりたくない場合は、銀行振込でも承りますので
お知らせください。
```

⚠️ **LINEにカード入力画面のリンクを貼らないこと。** メールで届く請求書に一本化します。
LINEで送られたリンクにカード情報を入れる形は、詐欺の手口と見分けがつかないためです。

### ④ 発送を知らせるとき

```
本日、発送の手配が完了しました。

印刷会社から直接お届けしますので、
BYRON TIME とは別の名前で届きます。ご了承ください。

到着まで、もう少しお待ちください。
```

⚠️ 代行発送は「ご注文者様名義」で届きます。**送り主が誰になるかは、事前に一言伝えておくと安心されます。**

## Gmailを台帳として使う

スプレッドシートの台帳は続きません。**Gmailの1スレッドを台帳にします。**

- 受付番号（例 `BT-260822-4821`）で検索すれば、注文とお届け先の2通が揃います
- LINEでフォント・背景・使う写真が決まったら、**その受付番号のメールに自分あてで返信して追記**します
- ラベル「うちの子」を付け、対応中はスターを立てておくと未処理が分かります

## 見落としやすいところ

- [ ] 代行発送の指定（金額入りの納品書が同梱されてしまう）
- [ ] iPhone・iPadの**機種**（フォームは任意入力なので、空欄ならLINEで確認する）
- [ ] 背景の色は**グリップケースとモバイルバッテリーだけ**選べます。ボトルとアクリルにはありません
- [ ] 2点以上のご注文は、フォームでは1点しか選べません。LINEで追加を聞くこと
- [ ] 建物名・部屋番号の記入漏れ（フォームでは任意なので、マンション名がないときは念のため確認）
